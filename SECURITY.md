# Security policy

## Reporting a vulnerability

Report a suspected vulnerability privately, through the GitHub advisory form
of this repository (`Security` tab, `Report a vulnerability`). Do not open a
public issue for it, and do not describe it in a pull request.

Confirmed reports receive a fix and a credit in `CHANGELOG.md` unless the
reporter asks otherwise.

## Supported versions

There are no released versions yet. Once releases begin, the latest released
`vX.Y.Z` receives fixes through a new release.

## Scope

maelys-jsonrpc as published from this repository. A vulnerability in a pinned
Maelys dependency belongs to that repository; report it there.
